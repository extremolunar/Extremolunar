# Extremo Lunar

Proyecto dedicado a la exploración, observación y divulgación del entorno lunar mediante astronomía, tecnología y creación de contenido.

## Objetivo

Acercar la Luna al público mediante observación telescópica, retransmisiones en directo, investigación y contenidos divulgativos.

## Proyecto

Este repositorio contiene los recursos, documentación y desarrollo tecnológico relacionados con Extremo Lunar.
